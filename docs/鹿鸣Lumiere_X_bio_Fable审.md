# 鹿鸣Lumiere · X bio 审稿（Fable 审）

- 账号：展示名 **鹿鸣Lumiere**（已定，含中文）｜handle **@lumierebyai**
- 审稿范围：仅 X 个人简介（bio）。不涉及置顶、头图、推文。
- 硬限：整段 ≤160 字符（中英、标点、空格、换行全算）。下文字数为 Python `len()` 逐字符统计；另附「CJK 按 2 计」的保守值，两种算法全部候选都远低于 160，不存在超限风险。
- 边界检查：所有候选与终稿均未出现 咖啡 / 柯森 / Lab / 热点 / 工具新闻 / 提示词合集 等隔离词。

## 1. 中文 / 英文 / 混排：一句结论

**混排，且分工固定：中文定身份和口吻（第 1、3 行），英文只做可被搜索的关键词（第 2 行）。** 理由：展示名已是中英混合，handle 是英文，受众天然两头都有；纯英文会把中文老客户和国内同行挡在门外，纯中文会让 `AI short film / workflow / Agents` 这几个最有搜索价值的词消失。混排不是折中，是把两种文字各放到它最擅长的位置。

### A 现行微调
- 优点：第 1 行身份清楚、第 3 行是这套 bio 里唯一有「人」的句子，两者都已过关，动它反而是损失。第 2 行换成 `short films` 把定位从「做 AI 视频的」拉到「做短片的」，方向对。
- 问题：`workflows` 光秃秃一个词，和市面上所有「工作流博主」没区别，丢掉了你最硬的差异点「可复现」。`digital human` 被砍，但数字人仍在定位里，需要有地方接住（建议接到置顶，不必在 bio 里）。
- 结论：**底子最好，改一个词即可上。**

### B 心得向但仍守边界
- 优点：「做能交付的短片」是四个候选里最好的商业信号，一句话说清你不是玩票。
- 问题：
  - 「用镜头驯 AI」是博主式比喻，把 AI 拟成宠物/野兽，是 2023 年科普号的口吻，与「商业摄影师」的克制不搭。
  - `workflow notes` 的 `notes` 就是「心得 / 笔记」，正好踩在你说不做的「分享心得」边上：notes 一出，读者预期就变成「等更新看笔记」，而不是「看作品」。
  - 第 3 行重复展示名「鹿鸣Lumiere」，bio 顶上就是展示名，纯浪费一行。
- 结论：单独保留「能交付」这个意思，其余不用。

### C 更抓人（风险：略像博主）
- 优点：确实是最抓眼的。`films you can remake` 的方向（可复现）是对的。
- 问题：
  - 第 1 行「不是提示词，是工作流」用否定句定义自己，等于在 bio 里跟「提示词圈」吵架，读者第一眼记住的反而是「提示词」二字。观点型开场是 KOL 写法，不是制片写法。
  - `remake` 在电影语境里首义是「重拍 / 翻拍」，英文读者会读歪。
  - 「左手镜头，右手 AI」是现成套话，任何「摄影 + AI」账号都能贴，等于没写。
  - 全文没有「商业摄影师」四个字，身份最重的锚点丢了。
- 结论：**吸引度靠的是观点和对仗，不是你的作品，这正是「像博主」的来源。不上。**

### D 偏英文国际
- 优点：`reproducible workflows` 是四个候选里唯一把差异点写对的词，值得保留；关键词齐全，搜索友好。
- 问题：
  - `Photographer → AI producer` 的箭头是 LinkedIn 转行叙事，暗示「摄影是过去时」，而你两边都还在做。
  - `Workbench notes` 又是 notes，同 B 的问题。
  - 中文读者在这段 bio 里得不到任何一句中文，与「展示名含中文」的既定方向背离。
  - 第 3 行再次重复「鹿鸣Lumiere」。
- 结论：只抽走 `reproducible workflows`。

## 3. 推荐唯一终稿

**思路：A 的骨架 + D 的一个词。** 第 1、3 行沿用已过关文案不动，第 2 行三个关键词按「作品 → 方法 → 前沿」排序，把 `reproducible` 补回去，让「工作流」这个人人都写的词变成只有你在写的「可复现工作流」。

```
商业摄影师｜AI制片
AI short films · reproducible workflows · Agents
把新东西放到工作台上，看它能不能发光。
```

- 字符数：**79**（含 2 个换行、全角竖线、全角标点、空格）；CJK 按 2 计的保守值 **106**。硬限 160，余量充足，不需要为字数牺牲任何词。
- 三行分工：第 1 行「我是谁」（中文，商业信号）；第 2 行「搜什么能搜到我」（英文，三个可被检索的名词）；第 3 行「我怎么干活」（中文，唯一带气质的句子，也是与咖啡侧完全无关的安全表达）。
- `digital human` 从 bio 移出而非放弃：数字人属于交付形态之一，放在置顶或作品推文里比放在 bio 更有说服力。若坚持保留，可用备选：`AI short films · reproducible workflows · digital human · Agents`（字数约 95），但第 2 行会变得拥挤，不建议。

## 4. 明确砍掉的词（bio 内不得出现）

| 砍掉 | 原因 |
|---|---|
| 心得 / 笔记 / notes / 分享 | 把账号预期从「看作品」改成「等更新」，是博主叙事，也与「不追热点、不做工具新闻」的边界相冲 |
| 博主 / 创作者 / creator / 内容 | 身份降级；「商业摄影师｜AI制片」已经是更高一级的身份，不要自降 |
| 提示词 / prompt / 提示词合集 | 即便是否定句（「不是提示词」）也不写，否则读者记住的是被否定的那个词 |
| 驯 AI / 左手镜头右手 AI / 玩转 / 解锁 | 现成套话，任何账号可贴，零辨识度 |
| `→`（Photographer → AI producer） | 暗示摄影是过去时，与双线并行的事实不符 |
| 「鹿鸣Lumiere」写进 bio 正文 | 展示名已在 bio 上方，重复占行 |
| `remake` | 电影语境首义是翻拍，会读歪；要表达可复现用 `reproducible` |
| 教你 / 每天更新 / 关注不迷路 / 任何 emoji | 流量号话术，与克制口吻冲突 |
| 咖啡 / 柯森 / Lab 及任何相关暗示 | 硬隔离，本次全部候选均已通过检查 |

## 5. 这样写会不会「更吸引很多人」——诚实说边界

**不会带来更多人来，但会让来了的人更愿意留下。** bio 不是流量入口，X 上没人是靠搜简介找到账号的；人是被一条短片推文、一次转发、一个置顶带到主页的，bio 的全部工作是在那 3 秒内回答「这人是真做东西的还是又一个 AI 博主」。这版终稿把答案压到三行：有身份、有可搜的方法词、有一句不像模板的话，转化率会好于现行版，但涨粉速度取决于置顶和作品，不取决于这 79 个字符。如果想「吸引很多人」，把力气花在置顶那条短片和它的工作流拆解上，bio 已经够用了，不要再往里塞。
